# TODO — Agent Debate

> **Pointer doc.** The submission guidelines (§2.2, §2.4, §2.5, §17.1) name
> `docs/TODO.md` as the project's prioritized task list. In this repo that role
> is filled by **[`TASKS.md`](TASKS.md)**, which is the canonical task list.

**The task list lives here:** [`TASKS.md`](TASKS.md) — the prioritized TODO with
status: epics, per-task priorities (P0/P1/P2), owners, dependencies, status
markers (`[ ]` todo · `[~]` in progress · `[x]` done · `[!]` blocked), and the
definition of done. It is updated as development progresses.
